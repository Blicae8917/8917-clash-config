# 规则文件说明

本目录只存放可以公开分享、经过审阅的分流规则，不存放节点、订阅、凭据、内部网络信息或完整运行配置。

## 文件职责

- `direct.list`：需要直连的公开规则。
- `proxy.list`：需要交给代理策略组的公开规则。

## 格式

文件采用 Mihomo `behavior: classical` 对应的纯文本格式，每行一条规则，例如：

```text
DOMAIN,example.com
DOMAIN-SUFFIX,example.com
IP-CIDR,192.0.2.0/24,no-resolve
```

空行和以 `#` 开头的行是注释。

## 新增规则前检查

1. 这条规则是否能公开，是否包含单位内部域名、地址或拓扑？
2. 它应当直连还是代理，是否可能影响登录、更新、内网访问或本地发现？
3. 来源是否清楚，许可证是否允许收录和再分发？
4. 是否可以用更小范围的域名规则，避免过宽的 IP 段或通配匹配？
5. 是否已在测试配置中验证实际命中结果？
